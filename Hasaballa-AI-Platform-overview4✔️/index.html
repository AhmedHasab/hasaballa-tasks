🧠 How to Use Hasaballa AI Platform

🟢 1. Smart Director – Automatic Mode
The user writes the entire script inside the chat window, then presses a single button to start the automatic process. The system will handle everything — from visual generation to final video output:
Workflow: 1️⃣Scenario input ➜ 2️⃣Press Auto Director ➜ 3️⃣Analyze ➜ 4️⃣Generate Visuals ➜ 5️⃣Generate Voices ➜ 6️⃣Add Soundscape ➜ 7️⃣Animate & Lip Sync ➜ 8️⃣Send to Timeline Editor

🟡 2. Smart Director – Manual Mode
Full hands-on mode for professionals who want total control. The user can control each generation step manually — generate visuals, skip voice, choose animation style, etc. Nothing happens automatically.
Workflow: 1️⃣Scenario input ➜ 2️⃣Press Manual Director ➜ 3️⃣Analyze ➜ 4️⃣Generate Visuals ➜ 5️⃣Generate Voices ➜ 6️⃣Add Soundscape ➜ 7️⃣Animate & Lip Sync ➜ 8️⃣Send to Timeline Editor
✅ Allows complete manual control at every step.

🔵 3. Standalone Mode (Each Tool Individually)
Use any tool separately (image generator, voice cloner, animation, etc.) without needing to run a full project. Ideal for experiments, assets, or testing workflows.

🧩 How the Platform Flows

  1. 1️⃣ User writes full script in Hasaballa GPT Chat.
  2. 2️⃣ User clicks Auto Smart Director or chooses Manual Mode.
  3. 3️⃣ The system processes the script → generates visuals, voices, animations, and lip sync.
  4. 4️⃣ All assets go into the Timeline Editor.
  5. 5️⃣ User can fine-tune scenes via Smart Edit Layer.
  6. 6️⃣ Final video is exported in high quality (HD, 4K…).
  7. 7️⃣ (Optional) Track views/revenue via YouTube integration.
